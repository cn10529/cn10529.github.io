一、 Visual Studio 2008 SP1 安装与激活

1) 安装

下面的教程是详细的安装、激活、升级的步骤：

● 安装 .NET Framework 3.5 运行库

首先检查有没有安装 .NET Framework 3.5 运行库，若没有安装请按照以下步骤操作：

1. 双击

2. 右击以管理员身份运行

3. 安装

● 安装 Visual Studio 2008

现在开始正式安装 VS 2008 的主体

1. 使用压缩软件解压或直接打开当前镜像文件

2. 向下滑动，找到“setup.exe”,右击以管理员身份运行

3.

这里可以自定义调整，我这里安装默认的来安装

4. 现在就开始安装了，此操作可能会花费十几分钟，请您耐心等待！

5. 若您看到了这个界面，说明 VS 2008 已经成功安装，点击“完成”

6. 此时，会退回到此界面，但不要退出，放在旁边备用，若您已经退出，请重新找到“setup.exe”,右击以管理员身份运行

2) 激活

现在，VS 2008 已经成功的安装了，但现在仍是 90 天试用期，超过90天，程序将强制让您激活，否则程序会自动退出

1. 回到这个界面，打开“激活工具”文件夹

2. 以管理员身份打开“UpgradeVs2008.exe”

3. 此时会出现这个窗口，先放在旁边备用

4. 再次回到刚才保留vs安装程序窗口，再次点击第一个选项

5. 这时候出现了再次出现了这个界面，但不要点击下一步，若您已经点击，请重启安装程序

回到激活工具，点击“写入序列号并激活”

6. 此时回到安装界面，就可以点击下一步了

7. 然后就会发现这里多了一个选项，说明您已经成功的操作了，点击“升级”按钮

8. 此时会花费一些时间，就会跳转到这个界面，点击“完成”，就激活成功了

9. 此时，就可以点击“退出”了

貌似激活只能维持128天，128天后仍要重复此操作，所以激活工具和安装程序要时刻准备好

3) 升级到SP1 版本（必须！）

升级到 SP1 版本就会有更多功能，而且，也是 Windows Embedded Compact 7 所必须的环境

1. 回到这个界面，打开“VS2008_SP1_升级补丁”文件夹

2. 解压或直接打开此镜像文件

3. 然后打开“vs90sp1”文件夹

4. 向下滚动找到“SPInstaller.exe”，右击以管理员身份运行

5. 出现了这个窗口，点击“下一步”

6. 勾选协议，然后继续下一步

7. 此时，就已经开始安装了，此操作仍然需要几十分钟，请您耐心等待！

8. 出现这个界面，点击“完成”

二、 Windows Embedded Compact 7 安装

安装之前请先检查有没有安装 VS 2008 SP1，安装环境是否为 Windows 7，若没有，请参照 VS2008安装教程 来安装，注意版本VS必须是SP1，否则将不能安装

这是您从网盘下载的文件：

下面的教程是详细的安装的步骤：

1) 准备安装

1. 解压当前文件，进入目录

2. 进入文件夹“Microsoft Windows Embedded Compact 7”

就可以看到以下文件，这就是完整的 Windows Embedded Compact 7 开发环境安装包，这3个文件缺一不可：

将“dvd1.iso”“dvd2.iso”，分别解压或挂载镜像，放在旁边备用

2) 开始安装

1. 进入“dvd1.iso”或解压的目录，得到以下文件

2. 找到“WindowsEmbeddedCompact7.exe”，然后以管理员身份运行

就会出现以下界面

3. 点击开始安装

4. 勾选协议后继续

5. 此时要求输入产品序列号，将刚才解压的目录中的“license.txt”打开，里面就是序列号，直接输入或粘贴即可(PW28V-TRKP8-RW8JQ-QG8MF-23C7F），然后点击下一步

6. 然后就会出现这个界面，因为有一些功能我们是用不到的，因为我们只要在虚拟机中运行，为了节省磁盘空间，我们选择自定义安装，然后点击下一步

7. 由于我们的主要目的是要在虚拟机中体验，所以只要核心部分 + x86 架构，选择前面4个选项+最后一个选项，然后点击下一步

8. 现在到了准备就绪的界面了，检查无误后（注意磁盘的剩余空间，空间不足会报错），点击“Install”开始安装

9. 现在，安装正式开始，不出意料的话肯定会填出下面的弹窗

10. 这个窗口是在提示我们需要插入 扩展资源镜像 也就是一开始解压目录的“dvd2.iso”，现在就排上用场了

请先确保您已经插入“dvd2.iso”或已经解压到目录，然后点击“Browse...”浏览的按钮

在“浏览文件夹”窗口中进入“dvd2.iso”或者解压的目录，然后逐步展开“OS\processor\x86\”文件夹，然后点击“确定”

回到了这个界面，现在点击“OK”

就会发现正常继续安装了，此过程可能会花费十几分钟，希望您耐心等待！

11. 当您看到这个界面时，就说明Windows Embedded Compact 7 的开发环境已经成功地安装了，直接点击“Finish”完成按钮完成安装

三、 Virtual PC 2007 SP1 安装、设置中文

安装之前请先检查安装环境是否为 Windows 7，否则程序将不能正常工作。之所以安装这个虚拟机，是因为它原生支持WindowsEmbeddedCompact7构建的镜像的驱动，体验感更加，也更兼容

这是您从网盘下载的文件：

下面的教程是详细的安装的步骤：

1) 安装主体

1. 检查您的Windows系统是64还是32位，选择对应的版本运行

2. 我这里以64位为例，以管理员身份运行

3. 然后就会出现这个窗口，点击下一步

4. 同意协议，然后点击下一步

5. 这是自定义您的信息的一步，可以直接保持默认，点击“下一步（Next）”

6. 这是自定义安装位置的一步，若您想要自定义，请务必记住路径，后面汉化要用到，我这里保持默认，直接点击“安装 (Install)”开始安装

7. 当出现了这个界面，说明安装完成了，直接点击“完成 (Finish)”以完成安装

2) 安装中文语言包

1. 回到刚才的这个目录，以管理员身份运行“Virtual PC 2007 中文语言包.exe”

2. 出现了这个窗口

选择您刚才的 Virtual PC 2007 SP1的安装的目录，我这里已经是默认的目录，所以不必修改，所以点击“安装”

然后窗口可能会突然消失，这个现象说明安装成功完成，这是可能会跳转到一个网页，我们把它关闭即可

3) 设置中文语言

1. 安装完成后桌面可能不会显示快捷方式，所以点开开始菜单，找到“Microsoft Virtual PC”的选项，点击

就会出现以下界面

2. 这时可能会立刻弹出这个窗口，这个窗口的意思是新建虚拟机，可我们的目的并不是新建虚拟机，而是设置中文语言，所以点击cancel取消

回到这个界面，按我的步骤操作：

在菜单栏点击“File”>“Options”

这个窗口中在“Language”栏里，下拉框中选择“Simplified Chinese”

之后点击“OK”

3. 然后重启程序

按刚才的方式打开后，就会发现界面变成了中文

至此，Windows Embedded Compact 7 开发环境安装 已经全部完成！
