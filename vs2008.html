Visual Studio 2008 SP1 安装与激活教程

这是您从网盘下载的文件：

下面的教程是详细的安装、激活、升级的步骤，为了能确保正常使用WEC7，建议安装环境使用 Windows 7

一、安装

1）安装 .NET Framework 3.5 运行库

首先检查有没有安装 .NET Framework 3.5 运行库，若没有安装请按照以下步骤操作：

1. 双击

2. 右击以管理员身份运行

3. 安装

2）安装 Visual Studio 2008

现在开始正式安装 VS 2008 的主体

1. 使用压缩软件解压或直接打开当前镜像文件

2. 向下滑动，找到“setup.exe”,右击以管理员身份运行

3. 安装向导

这里可以自定义调整，我这里安装默认的来安装

4. 现在就开始安装了，此操作可能会花费十几分钟，请您耐心等待！

5. 若您看到了这个界面，说明 VS 2008 已经成功安装，点击“完成”

6. 此时，会退回到此界面，但不要退出，放在旁边备用，若您已经退出，请重新找到“setup.exe”,右击以管理员身份运行

二、激活

现在，VS 2008 已经成功的安装了，但现在仍是 90 天试用期，超过90天，程序将强制让您激活，否则程序会自动退出

1. 回到这个界面，打开“激活工具”文件夹

2. 以管理员身份打开“UpgradeVs2008.exe”

3. 此时会出现这个窗口，先放在旁边备用

4. 再次回到刚才保留的 vs 安装程序窗口，再次点击第一个选项

5. 这时候出现了这个界面，但不要点击下一步，若您已经点击，请重启安装程序

回到激活工具，点击“写入序列号并激活”

6. 此时回到安装界面，就可以点击下一步了

7. 然后就会发现这里多了一个选项，说明您已经成功的操作了，点击“升级”按钮

8. 此时会花费一些时间，就会跳转到这个界面，点击“完成”，就激活成功了

9. 此时，就可以点击“退出”了

貌似激活只能维持128天，128天后仍要重复此操作，所以激活工具和安装程序要时刻准备好

三、升级到 SP1 版本（必须！）

升级到 SP1 版本就会有更多功能，而且，也是 WindowsEmbeddedCompact7 所必须的环境

1. 回到这个界面，打开“VS2008_SP1_升级补丁”文件夹

2. 解压或直接打开此镜像文件

3. 然后打开“vs90sp1”文件夹

4. 向下滚动找到“SPInstaller.exe”，右击以管理员身份运行

5. 出现了这个窗口，点击“下一步”

6. 勾选协议，然后继续下一步

7. 此时，就已经开始安装了，此操作仍然需要几十分钟，请您耐心等待！

8. 出现这个界面，点击“完成”

至此，VS 2008 安装、激活、升级，已经全部完成！

感谢观看！
